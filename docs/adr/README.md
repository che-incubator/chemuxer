# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Chemuxer. ADRs capture the context, decision, and consequences of significant architectural choices.

ADRs are immutable — when a decision is revisited, a new ADR supersedes the old one rather than editing it.
